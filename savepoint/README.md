# Savepoint

Mobil uyumlu, Excel'deki 199 oyun ve 6 öncelik aşamasıyla çalışan kişisel oyun backlog takipçisi.

- Durum, puan ve notlar bu tarayıcıda saklanır.
- JSON yedek alıp içe aktarabilir, CSV dışa aktarabilirsin.
- Kapaklar internete bağlıyken Steam/Wikipedia kaynaklarından eşleşme bulunduğunda yüklenir; diğer oyunlar tasarımlı metin kapakları kullanır.
- Kişisel ilerleme verilerini cihazlar arasında otomatik eşitlemez.
