BULUT EŞİTLEME / TELEFON + PC

Savepoint senkronizasyonu

GitHub Pages tek başına kayıtlarını cihazlar arasında taşıyamaz. Ücretsiz Firebase kurulumunu bir kez yapınca oyun durumları, puanlar ve notlar şifrelenerek bulutta tutulur ve diğer cihazda aynı kodla eşitlenir.

İlk kurulum (bir kez)
  1. Firebase Console’u aç; proje oluştur, Project settings → General bölümünde Web API Key ve Project ID’yi al.
  2. Build → Firestore Database bölümünden veritabanı oluştur.
  3. Authentication → Sign-in method içinde Anonymous girişini etkinleştir.
  4. Aşağıdaki kuralları Firestore → Rules bölümüne yapıştırıp yayınla.
  5. Bu cihazda “Ayarları kaydet” ve “Eşitle şimdi” de. Diğer cihazda aynı Project ID, API Key ve eşitleme kodunu gir.
Bulut eşitlemesi henüz kurulmadı. Yerel kayıt çalışıyor.
Firestore Rules

Kurallar yalnızca giriş yapmış oturumlara erişim verir. Kayıt içeriği ayrıca eşitleme koduyla şifrelenir; bu kodu kimseyle paylaşma.

rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /savepointBacklogs/{syncId} { allow get, create, update: if request.auth != null; allow list, delete: if false; } } }
